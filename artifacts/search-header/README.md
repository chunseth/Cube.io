# Cube.io — App Store header artwork

- `cubeio-search-header-3840x1646.png` — wide header, 3840 × 1646.
- `cubeio-search-header-5244x2950.png` — universal artwork, 5244 × 2950.
- Matching SVG files are editable vector sources with the text outlined.
- The preview files are reduced-size images for review, not upload.

Both upload PNGs are opaque RGB. The taller version preserves the artwork's proportions and adds vertical space. Preview the chosen asset in App Store Connect to check its placement.

The layout uses a flat dark navy background, the app's actual Aa Perm U-face and four side strips, its cube colours, and a published Aa algorithm from the app catalog. No generated photography or illustration is used.

Apple's creative asset specifications: https://developer.apple.com/help/app-store-connect/reference/app-information/creative-assets-specifications
