# Cube.io search-results artwork

Use `cubeio-search-results-3840x2560.png` in App Store Connect's Search Results asset slot. `cubeio-search-results-1920x1280.png` is the smaller export of the same artwork.

Both files are 3:2 opaque RGB PNGs. The layout uses the real Timer, Algorithms, and Progress screens with a small title on the app's dark blue background. Screens show sample practice data. System status bars are cropped out; the app content is unchanged.

`cubeio-search-results.svg` contains the same composition with embedded screenshot images and title text converted to paths.

Apple's specifications: https://developer.apple.com/help/app-store-connect/reference/app-information/creative-assets-specifications
